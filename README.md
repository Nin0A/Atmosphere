## Interopérabilité - Projet atmophère

### Auteurs

- Nino Arcelin
- Nicka Ratovobodo

### Description

Ce projet consite en une page PHP qui croise les données de plusieurs API permettant des des informations sur tout le Grand Nancy notamment les problèmes de circulations.

### Fonctionnalités

- Affichage de la météo du jour
- Affichage de la carte de la ville avec incidents sur le Grand Nancy
- Ajouter des points sur la carte
- Données liées à la qualité de l'air

### Technologies utilisées

- HTML/CSS
- JavaScript
- PHP
- XSL/DTD
